# Harbor Web

React provider console for reviewing care requests from Nova API.

## Run

```bash
npm install
npm run dev
```

Default port: `5173` (proxies `/api` to `http://localhost:8080`)

## Structure

- `src/pages` — top-level screens
- `src/components` — UI building blocks
- `src/api` / `src/hooks` — data fetching
- `src/utils` / `src/constants` — shared helpers
